# Advanced Incident Response Planning and Execution (NIST Framework)

## Project Overview
This repository features an advanced Incident Response Plan mapped strictly to the NIST SP 800-61 r2 guidelines. It includes an automated Python script that simulates an active cybersecurity incident (Phishing credential theft leading to data exfiltration) and executes targeted containment and remediation playbooks.

## Directory Structure
- `plans/`: Holds the formal `nist_incident_response_plan.md` framework blueprint.
- `simulations/`: Contains the `ir_exercise_simulator.py` execution engine.
- `logs/`: Stores the runtime audit log `simulation_output.txt` from the exercise.
